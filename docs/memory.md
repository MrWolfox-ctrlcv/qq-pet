# 宠物自主记忆

记忆由宠物主对话模型判断，并通过 `MEMORY` 工具执行；不再按“我喜欢”“记住我”等关键词启动独立的事实抽取器。模型可以在自然对话中查询、记录、修改、合并、纠正、遗忘及恢复，维护人物别名、交流画像和好感度。调用成功后才应声称已经完成。

阶段性回顾沿用可配置的消息批次及空闲计时，使用宠物的主模型、人设和已有记忆生成摘要、人物认识及记忆操作。模型可以选择完全不写记忆；已有同义内容应更新或合并，避免不断新增。它不再使用另一个廉价模型每人追加若干“事实”。回复判断和上下文压缩仍可使用廉价模型，两者不负责决定长期记忆内容。

记忆类型区分事实、偏好、经历、印象、角色梗和待确认。玩笑、短暂情绪、引用及图中人物不能直接当作发言者的现实特征。人物以QQ号归属，昵称优先放入人物别名；主人的身份与运行配置由正式配置提供，记忆文字不能覆盖程序规则。

工具提供 `search/list/get/add/update/merge/forget/restore/profile`。新增需真实消息来源；修改、合并、遗忘与恢复需已有ID和版本。不存在、来自未来或越过当前会话的来源会被拒绝；旧迁移资料没有原文时必须保留缺少来源的状态，不能补造引文。语义取舍由模型决定，因此仍可能判断错误，面板提供人工纠正与锁定。

程序限制数据范围、验证消息存在与版本、保护人工锁定并记录修订。新记忆默认属于来源会话，群聊工具不能读取私聊记忆，合并不能扩大不同条目的公开范围。遗忘是可恢复的隐藏，合并保留来源及旧版本；阶段操作结果保存在聊天检查记录中。

面板“设置与备份 → 宠物可用的工具 → 自主记忆与人物认识”控制模型记忆操作。关闭后，自然聊天和阶段回顾均停止修改记忆与画像；阶段会话摘要仍可单独记录。提示词页的“自主记忆整理原则”可调整宠物的记忆偏好。

记忆页展示人物QQ、记忆类型、来源数量及遗忘状态；缺少原文依据的旧迁移记录不会被标为已经核实。
