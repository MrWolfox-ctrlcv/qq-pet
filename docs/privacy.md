# 公开版的数据边界

公开仓库从单独的源码副本创建，没有沿用部署目录的 Git 历史。

包含后台、面板、原生桥接的自有代码，配置生成脚本、文档和合成测试。测试中的账号、名称、群号和消息均用于程序验证。

不包含运行数据目录、SQLite 数据库及其 WAL、聊天与转发记录、记忆、人物画像、好感度、人设提示词、模型服务密钥、QQ 登录态、令牌、个人图片或表情包、截图、机器路径、私人网络地址、QQ 客户端程序与提取代码、依赖或模型二进制，也不包含旧协议提供器与自动启动实验。

原先写死的主人账号默认值已移除；没有配置主人时不会将任何固定账号视为主人。原生桥接的 QQ 路径、账号、端口、数据目录和文件哈希均需由部署者提供。

`.gitignore` 排除了运行目录、私有配置、数据库、日志、常见媒体与二进制文件。公开提交前还检查了实际文件清单、私人标识、密钥模式和本机已配置密钥的精确匹配。以后发布新内容仍需检查，忽略规则不能替代审查。
