# 同一个QQ的独立人格

同一QQ号可以配置多个人格，每个人格使用独立的pet ID。同一时刻仅激活一个，QQ账号登录保持不变。若桥接地址和令牌相同，切换直接复用已有连接，不再开第二条连接或重新登录QQ。

每个人格独立保存提示词、记忆、图库、表情包、素材编号、人物认识与别名、好感度、原始聊天、话题、图片归属、阶段摘要和用量。新建人格不复制旧人格的内容；文件存储可按哈希去重，但素材目录与模型工具权限按人格隔离。查历史、读消息、按素材编号取图及管理记忆均不能越过当前人格的数据范围。

只给当前人格归档收到的新消息。切走期间的聊天不会自动补进另一个人格；切回后保留原来的资料继续使用。账号级消息归属记录防止桥接重连重放旧消息时被另一人格重新接收。运行时发送的消息由对应人格归档，忽略QQ自己发出的原生回显，避免回显跨人格。

面板上方“同号人格”按钮切换当前QQ的全部会话。侧栏选择仅用于查看资料，查看不激活人格。“Pet与提示词 → 人格名称”可以改名，人设独立编辑。主人可以发送 `#人格` 查看当前人格及名字列表，或 `#人格 名字` 切换；主人QQ号来自各人格配置。非主人命令不触发切换，模型本身没有任意切换其他人格的工具。

切换会使旧人格未完成的回复和后续工具调用失效，排队消息不在切回后补发。已有记忆和素材不会删除。已交给QQ的发送请求不能通过撤销模型任务回收，发送状态继续保留实际结果。

配置时创建两个不同pet ID，填相同的QQ账号；桥接地址、令牌和主人QQ配置一致，分别配置模型和提示词。账号密钥仍只保存在本地私有配置。服务加载时按持久化的激活记录启动当前人格，停用的人格不额外建立连接。

管理接口需管理员登录和CSRF：

- `GET /api/pets/:id/personalities`：同号人格列表、当前人格和版本。
- `POST /api/pets/:id/personalities/activate`，请求 `{ "version": 1 }`：激活路径中的人格；版本冲突时刷新列表再试。

切换不会清除原来的暂停设置。未激活、暂停或QQ离线是不同状态，可在总览区分。
